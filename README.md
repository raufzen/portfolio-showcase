## 🚀 Deploy to Vercel

Click the button below to deploy this showcase directly to your Vercel account:

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fraufzen%2Fportfolio-showcase)

### Deploying via Vercel CLI

```bash
# Install or run Vercel CLI
npx vercel

# Deploy directly to production
npx vercel --prod
```

---

## 🛠️ Local Development

```bash
# Clone the showcase repository
git clone https://github.com/raufzen/portfolio-showcase.git
cd portfolio-showcase

# Install dependencies using pnpm
pnpm install

# Start local dev server
pnpm dev
```
